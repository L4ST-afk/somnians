# 题图 · cover

`docs/cover.jpg` — 1280 × 853，286 KB，README 与 GitHub 社交预览引用这一张。作者：L4ST-afk。

**原件不在仓库里**。1536×1024 的 Photoshop 源文件与未压缩原图（16 MB + 1.2 MB）留在作者本地归档（坚果云 `Ob/Natan/蝶花半梦-仓库/归档快照/`）。理由：16 MB 的 PSD 一旦进 git 就永久留在包里，每个克隆者都得背一份；仓库只该有它需要的那一版。

改图时按这条走，别把原图塞回来：

```bash
sips -Z 1280 -s formatOptions 72 <原图> --out docs/cover.jpg
```
